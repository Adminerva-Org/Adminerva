Scoring and privacy

Starter missions offer 20 points, minus 2 per incorrect scored answer, with a minimum reward of 10. Standard offers 30 / −3 / minimum 15. Challenge offers 40 / −4 / minimum 20. Only an explicit scored answer changes a mission's possible reward; running code and compiler errors do not. Missions reward once per season. Public leaderboard participation is optional and uses aliases. This authorized class view maps aliases to roster names privately.

No season record means a saved current-season total is unavailable; it does not establish mastery or a zero school score. Earlier completions remain preserved below.
