Start here

Sign in with an account approved by your school. Student Home opens learning tools and Project Hub. Staff Home opens review, assessment, gradebook and lesson tools. A missing or disabled control can indicate a permission or evidence-state requirement; read the explanation before retrying.

Project Hub and evidence

  1. Open an assessment. Expand instructions or the rubric when needed.
  2. Select committed changes that represent your own work and choose a pinned checkpoint. Shared project source is context, not proof that every member contributed.
  3. Submit evidence. Before approval, withdraw to edit your selections and resubmit. Clearing a local selection does not delete a saved submission.
  4. After approval, ask the instructor to reopen evidence. Protected or published grades require deliberate instructor revision; earlier evidence remains in the audit history.

Review and Grade

  1. Review: inspect selected diffs and matching checkpoint source within the workspace. Verify individual contributions and approve evidence, or reopen it with a reason.
  2. System evaluation draft: select Evaluate when requirements are met. Check coverage and criterion explanations. Copy a suggested score or feedback only if you agree.
  3. Teacher score and feedback: enter or revise your own judgement, save a private draft, then separately confirm publication. Saving does not automatically publish.

Adminerva Auto Checker provides automated assistance. Evaluation details identify its origin, provider where applicable, and limitations. A draft is not an instructor-approved grade. Missing teammate screens must not automatically lower an individual's contribution score, and shared screens cannot earn credit for a noncontributor. A single XML file cannot establish the completeness, functionality or authorship of an entire application.

Playground, XML Layout Lab and Practice

Code Playground lets you edit and run supported code; save or export your work before leaving. XML Layout Lab translates a supported subset of Android layout XML into a sandboxed browser preview. It is not an Android emulator: full constraints, resource resolution and runtime behavior need Android Studio. Practice completions give personal practice points. Independently reviewed missions and explicitly published, opted-in alias standings are separate from assessment grades.

Lesson Planner and Slide Editor

Save a lesson, open its Slide Editor link, and create an editable starter. Private lesson remarks are excluded. Source version details help identify lesson changes; existing slide edits are not silently replaced. Inspect and edit each slide before classroom use. The editor is not a full Canva-style design suite.

Two kinds of analytics

Teacher Analytics focuses on academic progress, reviewed practice and assigned students' optional coarse engagement snapshots. Administrators can select a configured instructor in this same teacher view. Administration Analytics focuses on usage, returning visits and support. Raw diagnostic activity and system bug management are not teacher analytics. The school's current staff authorization mapping must be expanded before adding more instructors.

Time means approximate active foreground use, not time spent learning, attendance or effort. Repeated visits mean returning on different UTC days within the observed window, not a validated retention rate. Samples, consent gaps, idle detection and offline use make these numbers incomplete. Never grade or discipline students based on these signals alone.

Optional hourly maintenance can refresh non-grading summaries and remove bounded batches of expired monitoring records. Both policy switches default off. An administrator must separately activate the backend and review privacy, costs and retention; a saved checkbox does not prove a worker is installed. The dashboard shows its last recorded server result.

Optional activity sharing

Open Help → Activity preferences after signing in. Sharing is off by default. If you enable it, Adminerva sends module identifiers, a small set of actions, approximate active seconds, your account/student identifier and timestamps. It does not collect typed text, source code, passwords, full URLs, mouse coordinates or session recordings. Guests are not tracked by this feature.

A separate optional diagnostic switch keeps at most 20 allowlisted actions in memory on the current page. To share that trail, explicitly tick the attachment box when sending a report to the administrator. Teachers do not receive that trail. Stopping sharing blocks new events immediately. If the optional backend consent handler is installed, it removes the student's rows from the latest teacher snapshot when the change is processed; otherwise an administrator must refresh the snapshot. It does not erase earlier raw records. Contact your administrator for deletion. Events and trails carry 30-day expiry timestamps; expiry alone is not deletion. Separately activated cleanup is bounded and can leave a backlog; manual cleanup or approved server retention policies may also be needed. Account preferences and latest teacher summaries are stored separately. Device preferences should be disabled before using a shared computer.

Loading and reporting a problem

The global status indicator describes work still in progress; it is not a guarantee of success. Wait for the page's completion or error message. If a process fails, preserve unsaved work, then retry. Report system bugs to an administrator and class concerns to a teacher. Include the module, expected result and reproduction steps. Remove names, credentials and unrelated private information from screenshots. Adminerva does not deploy permission changes or publish grades automatically.
