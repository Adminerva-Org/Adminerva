Bulk evaluate assessment submissions

Select up to 20 eligible ungraded student submissions per batch; GitHub/repository evidence is capped at 10 because its frozen commit and source evidence is substantially larger. GitHub students need an actual selected-commit submission, not a teacher approval. Instructor-discovered or zero-commit GitHub records are excluded automatically. Studio, GitHub, essays and written/link assessments share the same grading controls but use different frozen evidence. Completed JSON batches clear and the next source-appropriate learner batch is selected automatically. Internal AI checks learners individually within the batch; External AI receives one shared rubric plus independent anonymous evidence items up to the source-specific batch limit when the package fits its context limit. Pending rubric points can be resolved directly in each expanded learner by entering the final criterion score; zero, stale and unverifiable submissions still require individual attention. Grades are saved privately; publication is always separate.

External AI batch exchange

The package stores the shared assessment instructions and rubric once; each anonymous item contains the assigned personalized task, frozen Studio code, GitHub checkpoint evidence, essay response, or submission link as applicable. External links are not automatically fetched and cannot establish the contents of another website. External AI packages automatically include as many complete selected learners as fit within 800,000 formatted JSON characters (up to 10 GitHub or 20 other learners). Overflow learners are deferred, not truncated; individually oversized evidence needs manual review. Submissions may contain identifying text; inspect before sending outside Adminerva. Keep batch IDs and references unchanged.

This action never publishes grades and never replaces an existing grade.
